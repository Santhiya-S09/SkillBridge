OOP, Modules and Exception Handling

Learn how to organize Python programs using classes, objects, reusable modules and error handling.

1. Introduction to OOP

OOP stands for Object-Oriented Programming. It is a programming approach that organizes code using classes and objects.

Why do we use OOP?

  • Organizes code clearly.
  • Encourages code reuse.
  • Makes large programs easier to maintain.
  • Helps represent real-world entities.
Example: A Student can have properties such as name and age, and actions such as studying.

2. Classes and Objects

A class is a blueprint used to create objects. An object is an instance of a class.

Example:

class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def display(self):
        print(self.name)
        print(self.age)

student1 = Student("Alex", 21)
student1.display()

Explanation:

  • class Student: Creates a class.
  • __init__: Initializes object data.
  • self: Refers to the current object.
  • student1: An object of Student class.
  • display(): A method that displays student details.
Output: Alex and 21

3. Inheritance

Inheritance allows one class to reuse the properties and methods of another class.

Example:

class Animal:
    def eat(self):
        print("Animal is eating")

class Dog(Animal):
    def bark(self):
        print("Dog is barking")

my_dog = Dog()
my_dog.eat()
my_dog.bark()

Explanation:

  • Animal is the parent class.
  • Dog is the child class.
  • Dog can use the eat() method from Animal.
  • Dog also has its own bark() method.

4. Python Modules

A module is a Python file that contains reusable functions, variables or classes.

Example using a built-in module:

import math

result = math.sqrt(25)

print(result)
Output: 5.0

Common modules:

  • math – Mathematical operations.
  • random – Generates random values.
  • datetime – Works with dates and time.
  • os – Works with operating system features.

5. Exception Handling

Exception handling is used to manage errors that occur while a program is running.

Example:

try:
    number = int(input("Enter a number: "))
    print(10 / number)

except ValueError:
    print("Please enter a valid number")

except ZeroDivisionError:
    print("Cannot divide by zero")

finally:
    print("Program finished")

Important keywords:

  • try: Contains code that may cause an error.
  • except: Handles an error.
  • finally: Runs whether an error occurs or not.
