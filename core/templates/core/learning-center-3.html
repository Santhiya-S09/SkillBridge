Django & Database Integration 🚀

Learn how Django applications work with databases, manage data and build dynamic web applications.

1. Introduction to Django

Django is a high-level Python web framework used to build secure and maintainable web applications quickly.

Why Django?

  • Built using Python.
  • Provides built-in authentication.
  • Supports database operations.
  • Includes an admin panel.
  • Follows the MVT architecture.
Remember: Django helps developers build dynamic websites using Python.

2. Django Project and App

A Django project is the complete web application. An app is a module inside the project that handles a specific feature.

Create a Django Project

django-admin startproject myproject

Move into the project folder

cd myproject

Create an App

python manage.py startapp students

Important Django Files

  • models.py: Defines database models.
  • views.py: Handles application logic.
  • urls.py: Defines URL routes.
  • admin.py: Registers models in admin.
  • settings.py: Contains project settings.

3. Django Models and Database

A model is a Python class that represents a database table. Each model field represents a column in that table.

Example: Student Model

from django.db import models

class Student(models.Model):
    name = models.CharField(max_length=100)
    email = models.EmailField()
    age = models.IntegerField()

    def __str__(self):
        return self.name

Explanation

  • CharField: Stores text.
  • EmailField: Stores email addresses.
  • IntegerField: Stores whole numbers.
  • __str__: Returns a readable object name.

Create Database Migrations

python manage.py makemigrations

python manage.py migrate
Important: makemigrations creates migration files. migrate applies those changes to the database.

4. CRUD Operations

CRUD represents the four basic operations used to manage data in an application.

  • Create: Add new records.
  • Read: Retrieve records.
  • Update: Modify existing records.
  • Delete: Remove records.

Create a Record

Student.objects.create(
    name="Arun",
    email="arun@example.com",
    age=21
)

Read Records

students = Student.objects.all()

Update a Record

student = Student.objects.get(id=1)
student.name = "Kumar"
student.save()

Delete a Record

student = Student.objects.get(id=1)
student.delete()
CRUD operations help applications store, display, update and remove information.

5. Django Views and URLs

Views contain the logic that processes a request and returns a response. URLs connect a browser address to a view.

Example View

from django.http import HttpResponse

def student_home(request):
    return HttpResponse("Welcome to Student Page")

Example URL

from django.urls import path
from . import views

urlpatterns = [
    path('students/', views.student_home,
         name='student_home'),
]

When a user visits the students URL, Django calls the connected view function.
