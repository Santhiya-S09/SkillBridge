1. Introduction to Python

What is Python?

Python is a high-level, general-purpose programming language. It is popular because its syntax is simple and easy to understand.

Simple Tamil Meaning:
Python oru programming language. Computer-ku namma instructions kudukka idha use pannuvom. Idhoda syntax beginner-ku easy-ah irukkum.

Example: First Python Program

print("Hello, World!")

Output:

Hello, World!
Explanation: print() is used to display information on the screen.

2. Variables and Data Types

What is a Variable?

A variable is a name used to store a value in a program.

Variable-na oru value-ah store panna use panra name. Example: student_name, age, marks. 
student_name = "Santhiya"
age = 21
marks = 85.5

print(student_name)
print(age)
print(marks)

Output:

Santhiya
21
85.5

Common Python Data Types

name = "Python"       # String
age = 21              # Integer
price = 99.5          # Float
is_student = True     # Boolean
Remember:
String – Text values
Integer – Whole numbers
Float – Decimal numbers
Boolean – True or False

3. Python Operators

Operators are symbols used to perform operations on values.

Operators-na values mela calculations or comparisons panna use panra symbols. 
a = 10
b = 5

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a > b)

Output:

15
5
50
2.0
True

4. Conditional Statements

What is if-else?

Conditional statements help a program make decisions based on conditions.

Condition-na oru check. Condition True-na if block execute aagum. False-na else block execute aagum. 
age = 18

if age >= 18:
    print("Eligible")
else:
    print("Not Eligible")

Output:

Eligible

5. Loops

Loops are used to execute a block of code repeatedly.

Same code-ah repeated-ah execute panna loops use pannuvom.

For Loop

for i in range(1, 6):
    print(i)

Output:

1
2
3
4
5

While Loop

count = 1

while count <= 3:
    print(count)
    count += 1

Output:

1
2
3
